# Joshi Productions — Creative Production & Media Company

Based in Hyderabad, **Joshi Productions** is a full-service creative production house specialising in cinematic production, commercial filmmaking, photography, digital content, event coverage, studio production, and artist management.

> *"Creating Beyond the Frame."*

---

## 🚀 Features & Stack
- **Framework**: Vite + React
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Bespoke SVGs
- **Theme**: Clean Studio Light Theme with warm amber/copper brand accents
- **Design Highlights**:
  - Split-screen above-the-fold cinematic hero with interactive switcher
  - Filterable production services with editorial visual cards
  - Selected portfolio showcase with full-screen video player modal
  - Talent & Music Roster division (featuring releases *Jaisi Aapki Marzi* & *AMBSTER 50012*)
  - Live Instagram integration highlighting `@joshi_productions`
  - Mobile bottom floating quick-action bar (WhatsApp, Call, Book Shoot)
  - Interactive project inquiry & consultation modal
